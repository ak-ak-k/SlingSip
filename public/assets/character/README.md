# Character assets

SlingSip's final guardian is an original articulated SVG in `src/app/features/companion/companion-character.component.html`. Its web and bottle are also SVG, driven by `SwingAnimationService`. It does not load the legacy sprite/WebM clips described below. See [the Phase 7A report](../../../docs/phase-7a.md).

`development/` retains original vector sprite sheets generated by `node scripts/create-development-character.mjs` from the earlier movement prototype. Each transparent cell is 240 × 320 with feet at y=310. Walk has 12 articulated frames and a 110px cycle stride; idle has 16 breathing/blinking frames. The independent sprite/WebM utilities remain available for future asset experiments.

Configure primary assets in `src/app/features/companion/animation/character-assets.ts`. Supply transparent VP9 WebM files such as `walk-left.webm`, `walk-right.webm`, `idle.webm`, and optional `turn-left.webm`/`turn-right.webm`. Keep all clips on the same canvas, subject scale, and foot baseline, including transparent padding. Use seamless walk/idle loops, muted audio, and a one-shot turn. Do not bake screen movement into the walk video.

For legacy media experiments, retain the development sprite descriptors as per-clip load-error fallbacks.

For each WebM walk, set `stride` to the source-pixel distance per complete loop and `referenceHeight` to its source canvas height. The player adjusts playback rate to match screen movement. Without these fields the clip's configured `playbackRate` is used. Set `facing` to the clip's final/original orientation; the renderer mirrors only when necessary. Optional turn clips should have `loop: false` and end facing their declared direction. `durationMs` supplies a duration if video metadata is not finite.

Sprite sheets use one horizontal row. Specify cell width/height, frame count, fps, facing, playback rate, loop, and optional walk stride. All clips must use the same cell aspect ratio, subject scale, and foot baseline; update `CHARACTER_CONFIG.aspectRatio` when replacing the common canvas. Walking frames follow travelled distance, with a duration-derived stride when no explicit stride is given. Idle/turn use CSS steps playback.

The legacy configuration uses a 280px tall, 210px wide box. WebM and sprite clips are buffered before swapping so preparation does not blank the character. Missing/undecodable custom assets use the configured development fallback. Keep companion DevTools closed when checking native alpha.

No external artwork or video files are required for the final swing experience. If experimenting with the retained media utilities, supply matching transparent padding, seamless loops and no audio or baked-in screen travel; validate alpha with those actual files.

`companion-guardian.svg` is the static dashboard copy of that same artwork. The original mint drop badge and delivered bottle geometry remain unchanged. Development sheets are historical movement prototypes, not a separate mascot design.
