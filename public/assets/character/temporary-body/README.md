# Temporary frame-based fallback

Seventy-two authored vector pose frames in thirteen independent clips, generated by `scripts/generate-temporary-body-frames.mjs`. `frames.svg` contains body/head symbols; `manifest.json` records clips, durations and per-frame sockets. This is explicitly temporary art and is independent of the screen trajectory and reminder logic.

The reusable renderer accepts SVG symbols or transparent bitmap layers with alpha hit silhouettes. It remains the graphics-failure fallback for Phase 7E. See `docs/companion-3d-assets.md` for optional final fallback artwork.
